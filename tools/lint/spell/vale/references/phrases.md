# Phrase reference

Writers must replace each listed phrase with a named actor, action, condition,
measurement, or source. Text inside code samples and quotations remains exempt.

## Throat-clearing openers

- `Here is what matters`
- `It is important to note that`
- `It should be noted that`
- `Needless to say`
- `This is worth noting`
- `Before we begin`

Start with the fact that follows the opener.

## Emphasis crutches

- `clearly`
- `crucially`
- `extremely`
- `interestingly`
- `obviously`
- `remarkably`
- `significantly`
- `very`

Replace an emphasis word with a value, comparison, source, or boundary
condition. Scientific uncertainty terms remain valid if a method or result
supports them.

## Promotional and stock language

- `cutting-edge`
- `game-changing`
- `groundbreaking`
- `powerful`
- `production-ready`
- `revolutionary`
- `robust`
- `seamless`
- `state-of-the-art`
- `unlock the potential`

Name the tested property and the evidence for it.

## Vague quantities and claims

- `a lot of`
- `a significant number`
- `countless`
- `numerous`
- `several`
- `the implications are significant`
- `the reasons are structural`

Give a count, range, distribution, effect size, mechanism, or constraint.
