# Versioning standards

- [Commit messages](commit-message-guide.md): structure, trailers and DCO.
- [GitFlow](gitflow-guide.md): branches, integration and release flow.
- [Versions](versioning-guide.md): semantic versions, tags and prereleases.
- [Signatures](signature-guide.md): commit, tag and artifact signing.

Before submitting or publishing changes, check the applicable guide, commit format, branch and merge target,
version impact, required sign-off and signatures. Keep release tags, release notes and metadata consistent.
Follow the [release procedure](../../procedures/release.md) for candidate acceptance.
